# Java Encapsulation and Constructors Practice
This repository contains Java exercises focused on understanding encapsulation and constructors in object-oriented programming.

## Concepts Covered
- Encapsulation
- Constructors
- Classes and objects
- Access modifiers (private, public)
- Getter and setter methods
- Object initialization
- Object-Oriented Programming (OOP)

## Tools Used
- Java
- IntelliJ IDEA

## Purpose
To practice fundamental object-oriented programming concepts in Java, specifically encapsulation and constructors.
Encapsulation helps protect data by restricting direct access to variables, while constructors are used to initialize objects when they are created. These concepts improve code organization, security, and maintainability.
